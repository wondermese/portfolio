# Emese Gábor — Stills & Motion
Open index.html to preview; open admin.html to manage projects. Select a folder, enter titles/descriptions (English required, Hungarian and Spanish optional), select files or paste individual YouTube URLs, then save. Download each media file before closing the admin tab, put it in assets/ and export projects.js into the website folder. Reload index.html to see changes. Drafts are local; media files are not retained after closing the admin tab. Existing V2 projects can be copied into projects.js, but review their category in the manager and export again (legacy categories are mapped provisionally). 

Publish: create a public GitHub repository, upload the contents of this folder (not the ZIP), then Settings > Pages > Deploy from a branch > main > / (root). GitHub will show the URL. Keep videos on YouTube where possible. No server, automatic publishing or authenticated CMS is included. Do not publish private or NDA-protected media. The old CV was removed; when the new CV is ready, add assets/CV.pdf and replace the CV pending paragraph in index.html with a link to it (target="_blank" rel="noopener noreferrer").

Pictures includes AI Art & Visuals for AI-generated or AI-assisted still images.

Pictures also includes Food Photography (food) for restaurant, café and menu stills.
